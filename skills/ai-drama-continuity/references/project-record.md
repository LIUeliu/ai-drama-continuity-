# 项目记录模板

在每部剧自己的工作目录创建记录，勿把该剧内容写回通用技能。可用 Markdown；若已有 JSON 等结构，沿用它。以下字段按需要填写，不必空造大量条目。

## 项目与制作参数

- 剧名、工作目录、当前剧本路径、参照图库、逐段上传目录。
- 画幅；单次生成时长上限；每段图片上限（是否包含首帧）；视频模型及已知限制。
- 每集长度与结构；片头时长；首段片头与剧情是否同次生成。
- 同集/跨集首帧规则；是否有时间跳跃或循环。
- 声音、配乐、字幕、实物文字的生成/后期方式。
- 超额图片删减优先级；默认可采用人物侧面→手机背面→手机正面。必需身份/关键道具仍不足时先简化构图，不静默删除。
- 参数来源：用户确认 / 沿用项目 / 暂定。项目参数优先于技能示例。

## 固定设定

- 空间：布局观察方向、床桌门窗、通行路线、开门范围、固定物体高度。
- 人物：身份、服装、鞋、眼镜等识别物；每人现实实体数量。
- 物件：主人、款式颜色、数量、初始位置、可发生的变化。
- 剧情异常：允许的循环重置、幻象、物件消失；触发段号。

## 每次采用记录

- 段号、版本、源视频路径、用户采用依据；用户要求不改的范围。
- 检查方式：哪些连续区间、哪些抽帧、是否听过声音；不确定处。
- 真实尾帧文件与提取依据；若采用其他截点，记录用户选择及时间。
- 正常事实：人物→位置/高度/姿势/朝向/左右手；物件→位置/界面/状态/数量；光线与声音。
- 保留的生成错误：重复人影、几何变形等，不写成新设定。
- 下一段原计划与实际差异；受影响段号；准备采用的拍法。
- 已同步文件；待决定的问题。没有问题就不制造审批项。

## 交给下一位助手的话

本项目当前采用到【段号与版本】。已完成内容【范围】保持不变。下一段使用【提示词路径】，同集首帧来自【实际尾帧路径】。当前状态以【采用记录】为准；未知项为【具体内容】。不要运行旧版构建流程覆盖新提示词。用户后续提供“第几集第几段，这版采用”时，先检查新成片，再校准下一段及确有影响的后续内容。
