# 隐私与发布范围

本仓库发布通用 AI 短剧连续性工作流程及教程。使用者的项目资料与账号配置不属于仓库内容。

## 发布的文件

| 文件 | 内容 |
| --- | --- |
| `README.md` | 功能、安装、调用与交付说明 |
| `docs/使用教程.zh-CN.md` | 通用示例及制作步骤 |
| `docs/隐私与发布范围.md` | 发布范围与执行时的访问边界 |
| `skills/ai-drama-continuity/SKILL.md` | 通用工作指令 |
| `skills/ai-drama-continuity/agents/openai.yaml` | 技能名称、简介和调用示例 |
| `skills/ai-drama-continuity/references/project-record.md` | 未填写的项目记录模板 |
| `skills/ai-drama-continuity/references/prompt-and-delivery.md` | 提示词、完整 DOCX 和本地交付规范 |
| `.gitignore`、`.gitattributes` | 本仓库的文件排除与文本格式约定 |

不发布个人剧本、视频、图片、声音、真实项目记录、聊天附件、操作日志、原技能备份、登录会话、浏览器数据、环境变量文件或账号配置。教程中的磁盘路径是通用示例。

## 是否能据此访问账号

本仓库没有可执行脚本、外部服务接入配置、账号认证信息、API 密钥、私人接口地址或数据回传地址。安装仓库内容不会建立到作者 AI 账号、电脑或项目目录的连接。

技能是交给助手的说明，不能单独授予文件或账号权限。实际运行时，助手可以使用哪些文件和工具取决于所在环境以及使用者的授权。因此不能将一份说明文件的检查结果理解为对整个执行平台的安全保证。

工作指令要求只读取当前用户授权的项目和输入素材，不查找账号登录文件、凭据存储、密钥或无关个人资料。不要将此类资料填写到项目记录模板中。

## 公开 GitHub 身份

公共仓库会显示所有者的公开 GitHub 用户名，提交也会显示公开提交身份；访问者可以查看该账号已经公开的资料。公开发布不等于匿名发布。

发布时使用 GitHub 的非真实邮箱提交身份，避免把私人邮箱写入提交。仓库没有嵌入作者的真实邮箱、AI 平台账号或本地电脑用户名。

## 后续维护

提交新内容前检查正文、元数据、隐藏文件、Git 提交及文件链接。仅提交明确列入发布范围的文件；`.gitignore` 不能替代人工核对，也不能清除已经进入历史的内容。

反馈问题时使用匿名文字示例。不要在公开 Issue、提交或附件中上传账号凭据、未公开的项目素材或个人信息。
